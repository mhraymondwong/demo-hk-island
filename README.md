# 港灣示範市 · 香港政策島

這是一個虛構的「港灣示範市」政策島 Three.js 示範。場景、政策與數字皆為創作，並非真實的香港政府計劃或官方資料。

This is a fictional **港灣示範市** (Harbour Demonstration City) policy-island demo built with Three.js. The scene, policies, and figures are invented. They are not a real Hong Kong government plan or official data.

## 開啟 / Open

在瀏覽器打開 GitHub Pages：

Open the GitHub Pages site in a browser:

https://mhraymondwong.github.io/demo-hk-island/

需要網路連線，頁面才會從 jsDelivr CDN 載入 Three.js（`three@0.160.0`）。

A network connection is required so the page can load Three.js (`three@0.160.0`) from the jsDelivr CDN.

## 網址參數 / Query parameters

- `?lang=en` — 英文介面。English UI. 預設為繁體中文。The default is Traditional Chinese.
- `?skipOnboard=1` — 略過初次導覽。Skip the first-run onboarding.

例如 / Examples:

- https://mhraymondwong.github.io/demo-hk-island/?lang=en
- https://mhraymondwong.github.io/demo-hk-island/?skipOnboard=1
- https://mhraymondwong.github.io/demo-hk-island/?lang=en&skipOnboard=1
